# All About Me — Bilal Hussain

A responsive personal portfolio landing page for Bilal Hussain, a Software Engineering student at Iqra University, Islamabad.

## What's included

- `index.html` — complete responsive website (HTML, CSS, and JavaScript)
- `assets/favicon.svg` — custom BH favicon

## Run locally

Open `index.html` in a web browser. No build tools or package installation are required.

## Publish with GitHub Pages

1. Create a **public** repository named `all-about-me` in the GitHub account `bilalhussainturi`.
2. Upload `index.html`, `README.md`, and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub Pages will provide the published website URL in the Pages settings.

## Customize

Update the content in `index.html` as your skills, projects, and contact links grow. The current copy deliberately describes learning goals rather than claiming experience that has not been provided.
